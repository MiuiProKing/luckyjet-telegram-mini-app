Instagram 24/7 WEB

Панель вместо IPA. Логин и пароль отправляются только на твой Python-сервер.

GitHub Pages работает по HTTPS, поэтому сервер тоже должен иметь HTTPS.

Введите код панели и нажмите «СТАТУС».

Важно: Realtime MQTT Instagram — неофициальный механизм. Сервер может поддерживать foreground/keepalive, но Instagram сам решает, показывать ли зелёную точку «В сети».
