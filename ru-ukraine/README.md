# LuckyJet RU Ukraine

Рабочая русская версия страницы LuckyJet из AllPredictor.

## Файлы

- `index.html` - страница для запуска через GitHub Pages.
- `LuckyJet_RU_Ukraine.html` - та же готовая страница с понятным именем для скачивания.
- `LuckyJet_original.html` - исходная страница AllPredictor до перевода и исправлений.
- `luckyjet.jpg` - изображение LuckyJet, извлечённое из APK.
- `manifest.webmanifest`, `sw.js`, `icon.png` - установка на экран «Домой» и быстрый повторный запуск.

## Что исправлено

- интерфейс переведён на русский язык;
- время API переводится из UTC в `Europe/Kyiv` с учётом летнего времени;
- все кнопки имеют рабочие обработчики;
- основную кнопку можно использовать для отмены активного сигнала;
- ошибки сети и API показываются в интерфейсе;
- диапазон коэффициента по умолчанию установлен на `2.00x-8.00x`;
- активный сигнал сохраняется и восстанавливается после перезапуска страницы;
- при возврате в приложение состояние сразу синхронизируется с API;
- добавлена кнопка «НЕ ГАСИТЬ ЭКРАН» для iOS 18.4 и новее;
- оболочка страницы кэшируется сервис-воркером для быстрого запуска;
- удалён код Cloudflare, который не нужен в локальной и GitHub Pages версии.

Для работы сигналов требуется подключение к интернету и доступность API AllPredictor.

## iPhone

Откройте страницу в Safari, нажмите «Поделиться» → «На экран “Домой”», затем запускайте её с иконки. Кнопка «НЕ ГАСИТЬ ЭКРАН» удерживает экран активным только пока приложение видно. iOS всё равно может приостанавливать или выгружать веб-приложения в фоне, поэтому страница сохраняет сигнал и восстанавливает его при возврате.

Режим «Картинка в картинке» в Safari предназначен для видео и не может показывать всю интерактивную HTML-страницу поверх других приложений.
