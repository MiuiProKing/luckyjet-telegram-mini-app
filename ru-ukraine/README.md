# LuckyJet RU Ukraine

Рабочая русская версия страницы LuckyJet из AllPredictor.

## Файлы

- `index.html` - страница для запуска через GitHub Pages.
- `LuckyJet_RU_Ukraine.html` - та же готовая страница с понятным именем для скачивания.
- `LuckyJet_original.html` - исходная страница AllPredictor до перевода и исправлений.
- `luckyjet.jpg` - изображение LuckyJet, извлечённое из APK.

## Что исправлено

- интерфейс переведён на русский язык;
- время API переводится из UTC в `Europe/Kyiv` с учётом летнего времени;
- все кнопки имеют рабочие обработчики;
- основную кнопку можно использовать для отмены активного сигнала;
- ошибки сети и API показываются в интерфейсе;
- диапазон коэффициента по умолчанию установлен на `2.00x-8.00x`;
- удалён код Cloudflare, который не нужен в локальной и GitHub Pages версии.

Для работы сигналов требуется подключение к интернету и доступность API AllPredictor.
