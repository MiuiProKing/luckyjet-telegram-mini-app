# БОГ ХИЩНИК — Lucky Jet

Самостоятельная страница: index.html содержит все CSS и JavaScript.

Источник совпадает с пользовательским beta.html: GET https://xrniwkvfrtchtxjrwwgd.supabase.co/functions/v1/v0xff3-live?limit=…&offset=…&t=… (cache:no-store, Accept:application/json). Опрос последних результатов каждую секунду, полная модель 2000 раундов каждые 30 секунд. Все уникальные ID из полученной пачки сохраняются, одинаковые коэффициенты разных ID остаются разными раундами. При потере границы истории выполняется полное дочитывание. Сдвинутое или отсутствующее время не удаляет действительный коэффициент; исходная дата и время наблюдения разделены.

WebSocket разрешён сервером только для https://miuiproking.github.io. Другие адреса, включая предпросмотр ветки и file://, используют HTTP GET. Серверный сборщик этой версией не меняется; браузер получает только уже записанные им раунды.

Расчёт — статистические правила De/Ce и анализ последовательности. Отдельная нейросеть не подключена. Оценка правил не является вероятностью выигрыша. Неподтверждённые часы отключают точные временные циклы; наблюдения с приблизительным временем не увеличивают число подтверждённых попаданий.

Проверка: TZ=UTC node tests/bog-hishchnik-audit.test.mjs и TZ=Europe/Kyiv node tests/bog-hishchnik-audit.test.mjs. 24 сценария проверяют расчёты, сохранение новых коэффициентов, полную пачку, дубли, покрытие окон, архив и CSV. Источник интерфейса beta.html зафиксирован SHA-256 в tests/fixtures/beta-source-contract.json.
