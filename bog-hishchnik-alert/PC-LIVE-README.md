# Классическая версия с нашим сборщиком на ПК

Отдельная ветка `classic-pc-live-20261006`, основа `52944e4d2ce7595217afba850289fd66619bd6bf`. Старые ветки не изменены. Формулы классической версии, режимы, архив, журнал и русский интерфейс сохранены; преимущество прогнозов не доказано.

Страница размещена в GitHub; завершённые раунды поступают через защищённый HTTPS-шлюз из одной SQLite на ПК. Частота обновления истории — 1 секунда, полная выборка — 30 секунд. Файл `pc-connection.json` содержит только текущий адрес туннеля. При смене домена локальный процесс обновляет этот файл только в данной ветке. Страница обнаруживает смену адреса и переподключается с задержкой. При потере связи новые прогнозы блокируются.

Публичная страница просит отдельный код доступа только к чтению данных. В персональной ссылке код находится после `#access=` и не отправляется серверу GitHub. После открытия код сохраняется в sessionStorage текущей вкладки, фрагмент удаляется из адресной строки. Сохраните исходную персональную ссылку; при открытии обычной публичной ссылки в новой сессии потребуется код доступа. Не пересылайте персональную ссылку. Код даёт чтение коэффициентов/журнала, не управление ПК и не доступ к игровой сессии.

Игровая сессия, GitHub-авторизация и коды доступа отсутствуют в публичных файлах. CORS разрешён только для используемых GitHub Pages / githack origins, без сторонних cookie. Запись и локальные управляющие API недоступны удалённо.

На ПК: `work/luckyjet-sqlite-migration/START-AlwaysOn.cmd`. Работают один сборщик, SQLite, HTTPS-шлюз и небольшой обновитель адреса. `STOP-AlwaysOn.cmd` отключает фоновые службы и автозапуск до ручного старта. Все изменения публикации адреса происходят только в `classic-pc-live-20261006/bog-hishchnik-alert/pc-connection.json`.

Ноутбук должен оставаться включённым, не спать, иметь сеть и действующую игровую сессию. При выключении ноутбука страница GitHub открывается, но получение новых раундов и сигналы останавливаются. Бесплатный туннель и задержки GitHub CDN не дают гарантии непрерывности; период обрыва исключается из подтверждённых окон. Время Europe/Kyiv. Telegram не используется.
