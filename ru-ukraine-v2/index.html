Что изменено в V2

Старая версия не изменяется

Нет Math.random(), нет искусственного ±0.01 и нет confidence по той же выборке. V2 удаляет дубликаты round ID, строит признаки только из доступного прошлого, делает причинный walk-forward, отдельно считает baseline, Brier Score, ECE, автокорреляцию и distribution shift. Для совместимости источник данных V2 временно читает параметры подключения из старой страницы только во время выполнения и не дублирует их в новом исходнике. Для полной защиты секретов следующий шаг — заменить старые ключи и перенести источник в backend/Edge Function.

Исследовательский статистический инструмент. Исторические результаты не гарантируют будущий результат.
