# Lucky Jet ML · отдельная версия без Telegram

Старую ветку и её страницу не изменяли. Эта версия сохраняет источник коэффициентов, русский интерфейс, обычные/VIP/BIG-правила и добавляет вероятностную лабораторию. Для 2x доказанного улучшения нет, поэтому новые модели не выпускают подтверждённые сигналы. Отчёт: [bog-hishchnik-alert/ML_REPORT.md](bog-hishchnik-alert/ML_REPORT.md).

## Открыть веб-версию

Откройте опубликованную ссылку на `bog-hishchnik-alert/index.html` в новой ветке. Вход в Telegram не нужен. Устройства и вкладки имеют отдельные локальные хранилища; приватный режим браузера может не сохранять историю.

История читается с прежнего публичного Supabase v0xff3-live. Новые результаты опрашиваются раз в секунду, без наложения запросов; основная выборка обновляется раз в 30 секунд. Браузер использует IndexedDB для истории и фиксированных оценок. «Дочитать до 20 000» загружает дополнительную историю и не засчитывает старые записи как будущие результаты. Экспорт сохраняет JSON с уникальными раундами и журналом. День и время интерфейса — Europe/Kyiv.

`index.html` и `FULL_HTML.txt` теперь подключают соседние `runtime-config.js`, `ml-core.js`, `ml-client.js`, `ml-models.json`. Для локального просмотра запускайте HTTP-сервер, а не один HTML через file://:

```powershell
python -m http.server 8789 --bind 127.0.0.1 --directory bog-hishchnik-alert
```

Откройте http://127.0.0.1:8789/. Закрытие вкладки или сон устройства останавливает браузерный сбор. Потерянные окна исключаются из статистики.

## Настоящий SQLite и сбор при закрытой странице

Установите Python 3.10 или новее. Из распакованного каталога проекта:

```powershell
python local-server/server.py
```

Откройте http://127.0.0.1:8790/. SQLite/WAL создаётся в `.data/live.sqlite3`; сервер продолжает получать историю при закрытой странице, пока Python запущен, ПК работает и есть сеть. Не нужны CatBoost, Node или дополнительные пакеты для этого режима. Закрытие процесса/сон ПК останавливают сбор; после возвращения старые незавершённые оценки становятся unknown.

Сервер слушает только localhost. Собственные маршруты: `/api/live` — совместимая история из локальной SQLite, `/api/report` — здоровье и MAIN/BIG по отдельным целям/горизонтам, POST `/api/resume` — ручное снятие паузы 2x. Это наши локальные маршруты; адресов удалённого API не добавляли. Пауза применяется после двух ошибок основного 2x/3; вспомогательные перекрывающиеся горизонты не удваивают её счётчик. Параметры записанной оценки защищены SQL-триггером от последующей правки.

Веб-страница отдельно фиксирует свои оценки в IndexedDB; отчёт сервера относится к непрерывным наблюдениям сервера. Оба журнала помечают результаты как неподтверждённые наблюдения доставки, поскольку игровой порядок API не удостоверен. GitHub/githack раздают статические файлы и не запускают SQLite/Python автоматически.

Safari: предусмотрены запасные варианты AbortController и названия Europe/Kiev; физический iPhone не проверялся.

## Повторить обучение

Обучение необязательно для запуска готового приложения. Для воспроизводимого эксперимента используйте Python 3.12 и отдельное окружение:

```powershell
python -m venv .venv
.venv/Scripts/python -m pip install -r requirements-training.txt
.venv/Scripts/python ml-training/download_history.py
.venv/Scripts/python ml-training/train.py
.venv/Scripts/python ml-training/write_report.py
```

Публичная история меняется; новый снимок даст другую таблицу и hash. Параметры предзаданы, хронологические части разделены, модели не объявляются лучше по одной удачной цифре. Точные веса текущего эксперимента и контрольные примеры включены в эту версию. Сырые 20 000 записей текущего снимка сохраняются локально в рабочем каталоге и не публикуются.

## Ограничения

Все четыре семейства обучены и работают в браузере/локальном сервере, но к выдаче игровых сигналов не допущены. Независимая предсказуемость, полнота и игровой порядок источника не доказаны; редкие X требуют больше данных. Подробные Brier/log loss, калибровка, walk-forward, пропуски и серии ошибок: `ML_REPORT.md`, `MAIN_REPORT.md`, `BIG_REPORT.md`, `model-comparison.csv`, `ml-evaluation.json`. Ключи аккаунтов не нужны и не вставлены в HTML. Telegram отсутствует; никаких сообщений, ставок и внешних изменений приложение не делает.
