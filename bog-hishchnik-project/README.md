# БОГ ХИЩНИК

Отдельный проект на русском в ветке `bog-hishchnik-project-20260928`. Старые проекты не заменяются.

Откройте `index.html` вместе с остальными файлами каталога, либо готовый единый файл `БОГ_ХИЩНИК.html`. Для локального HTTP-просмотра можно запустить `python -m http.server 8767 --bind 127.0.0.1` из этого каталога и открыть http://127.0.0.1:8767.

## Возможности

- Эфир из существующей Supabase: поток событий и резервная проверка через секунду после завершения предыдущего запроса.
- Обычный и VIP-анализ последних 2 000 доступных результатов. Сигнал закреплён до конца окна независимо от открытого раздела.
- История по дате и часу, фильтры, загрузка выбранного дня или всей доступной базы, CSV.
- Карточки LuckyJet, Rocket Queen, Астронавт и Tropicana открывают указанные пользователем страницы AllPredictor в новой вкладке. Это ссылки на другие сайты, не подключение их коэффициентов к нашей базе.

## Исправление повторов

Старая база содержит пары записей с техническими ID `live-<время>-<коэффициент>` и `state-<время>-<коэффициент>`. Встречаются одинаковые результаты с разницей 0–2 секунды. Новая версия объединяет только такие технические записи одного коэффициента в пределах 2,5 секунды от фиксированной метки группы. Цепочки совпадений не объединяются бесконечно. Настоящие разные ID игровых раундов сохраняются независимо от совпадения коэффициентов.

Это фильтр вероятных технических повторов: без исходного ID нельзя доказать идентичность всех событий. Исходные записи в Supabase не удаляются; количество объединённых записей показано под эфиром. Фильтр применяется к эфиру, истории, CSV и модели. Сохранённые до исправления сигналы сброшены новой версией ключа хранения.

## Ограничения

Источник задан константой `API` в `app.js`: существующая функция нового проекта Supabase `xrniwkvfrtchtxjrwwgd`. Секретов и токенов в файлах нет. Серверный сборщик и старые файлы не изменены. Хранение ограничено тарифом Supabase. Фронтенд не восстановит раунды, которые сборщик не сохранил.

Проверка через секунду не гарантирует секундную доставку: влияют сборщик, сеть и замедление скрытых вкладок браузером. После возврата выполняется немедленная проверка. Новые прогнозы при устаревшей истории приостанавливаются. Баллы правил — не вероятность выигрыша.

Новая ветка сама не публикуется на GitHub Pages. Существующий workflow основного сайта не запускается, чтобы сохранить старую опубликованную версию.
