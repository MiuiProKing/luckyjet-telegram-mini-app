# Session ID на iPhone

Локальный просмотр session-id из URL игры и iframe через Safari Userscripts/Hyperweb. Страница index.html показывает исходник, позволяет скопировать код и скачать userscript.

Скрипт не читает cookies или localStorage, не отправляет ключи, не обновляет Supabase и не нажимает кнопки ставок. Действительность ключа не проверяет. Исторические адреса отдельно помечаются как потенциально устаревшие. Если session-id передаётся только в заголовке запроса, он не будет найден.

Реальных session-id, API-ключей и других пользовательских секретов в папке нет.
