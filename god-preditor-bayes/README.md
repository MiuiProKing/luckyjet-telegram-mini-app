# GOD PREDITOR · BAYES LIVE

Отдельная статическая страница с реальной историей Supabase и общим серверным
журналом окон. Сайт `MiuiProKing/MiuiProKing/luckyjet-time-echo` служил только
визуальным примером и не изменяется этим проектом.

## Запуск

Открой опубликованный `index.html` через HTTPS. Для локальной проверки:

```sh
python -m http.server 8769
```

Открыть http://localhost:8769/. Сборка, npm-пакеты и сторонний CDN не нужны.
`config.mjs` уже содержит публичные ключи существующего проекта Supabase.
Секретные ключи, Telegram-токены и игровые session-id в проект не входят.

## Расчёт

- Для 10×/40×/200×/500× используется Beta–Binomial с prior Beta(0.5,0.5).
- Для следующих трёх минут — Gamma–Poisson posterior predictive:
  `1 - (b / (b + 3))^a`, где `a = число событий + 0.5`, `b = экспозиция в минутах`.
- Диапазон 95% — неопределённость оценки при предположениях модели.
- Долгие раунды сохраняются; давность последнего большого X не повышает
  будущую вероятность сама по себе.
- Время задаёт будущее статистическое окно, а не подтверждённый оптимальный
  момент ставки. Преимущество над базовой частотой пока не подтверждено.
- CatBoost, Weibull и Hawkes не подписываются обученными моделями: для них
  необходим отдельный walk-forward и калибровка на последующих днях.

Круг показывает окно, зарегистрированное сервером. Параметры окна неизменяемы.
Результат проверяется строго после закрытия и внутри объявленных границ.
При пропусках — UNKNOWN, позднее подтверждение сохраняется отдельным событием.
Проверка показывает достижение коэффициента в истории, не результат реальной ставки.

## Данные и история

Свежие раунды запрашиваются каждые 5 секунд. Архив за доступные последние
90 дней загружается параллельно и кешируется в IndexedDB. Совпадающие значения
с разными ID сохраняются. Серверный расчёт окна использует последние 10 000
точных завершённых наблюдений; обзорные карточки — загруженный архив.
Время отображается в Europe/Kyiv. Полнота последовательности провайдера не
подтверждена; минутные интервалы не учитывают неизвестные пропущенные события.

Кнопка «История» открывает коэффициенты и общий журнал последних 50 окон.
Все события создания и результатов остаются в серверных таблицах.
Сервис вычисляет исходы при обращениях к API, без отдельного фонового cron.

## Проверки

```sh
node --test test/*.test.mjs server/*.test.mjs
```

Численные квантили сверены с SciPy. Тесты проверяют математические формулы,
защиту от утечки будущего, границы окон, пропуски, курсоры загрузки и журнал.
Они не доказывают предсказуемость игры или точность будущих сигналов.

Схема и backend: `server/README_RU.md`. Исходная история, сборщики, BeeAI
и прежние страницы не изменяются.
