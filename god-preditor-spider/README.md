# GOD PREDITOR · SPIDER LIVE

Самостоятельная статическая веб-страница с анимированным неоновым пауком, последними коэффициентами Lucky Jet, историей больших X и аналитикой времени по Киеву. Размещается на GitHub Pages без Python-сервера.

**Сайт:** https://miuiproking.github.io/luckyjet-telegram-mini-app/god-preditor-spider/

## Откуда данные

- Supabase project `stzrirukuxcyalrsstxx.supabase.co` — публичный клиентский **publishable key** из предоставленной пользователем конфигурации, `app.js`.
- Основная таблица `god_bayes_rounds_v1`; отбираются записи `estimated=false`, `coefficient`, `round_timestamp`, `feed_order`, `id`.
- Если основная таблица не отвечает, резервная `luckyjet_rounds` с `coefficient`, `played_at`.
- До 5000 последних подтверждённых раундов постранично. Свежая первая страница перепроверяется по REST каждые 15 секунд.
- Для основной таблицы дополнительно предусмотрена подписка Supabase Realtime `INSERT`. Если публикация/права доступа не позволяют подписку, REST продолжает работать. Сообщение Realtime служит только триггером для повторной подтверждающей REST-загрузки.
- CSV с историей, временем Киева и UTC, фильтры `≥10×`, `≥20×`, `≥40×`, `≥100×`, `≥200×`, `≥500×`.

Ключ указанного типа разрешён для использования в браузере, но доступ определяется правилами **RLS**. Никогда не добавляйте в публичный проект `service_role`, Telegram bot token, Gemini API key или чужие платные Premium-токены.

## Анализ и ограничения

Для четырёх порогов `20×/40×/200×/500×` рассчитываются частота, средний и медианный интервалы между историческими событиями, MAD и оценка базовой частоты хотя бы одного события в ближайшие 3 минуты по формуле `1 − exp(−λ·3)`, где `λ = число событий / число минут выборки`. Требуются как минимум 200 подтверждённых раундов, пять событий выбранной зоны и поступление раундов не старше 180 секунд.

Ориентировочное окно строится по медиане исторических интервалов. **Времена, значения и проценты не являются прогнозом с подтверждённой предсказательной точностью и не гарантируют выпадения коэффициента**. Материал исключительно для отслеживания истории и наблюдаемой статистики. Нет доступа к серверной AI-модели или закрытым Premium-обработчикам исходного сайта; они не имитируются.

Нажатие «ПОЛУЧИТЬ РАСЧЁТ» локально сохраняет окно на этом устройстве; после завершения приложение сверяет его со скачанной реальной историей и помечает как подтверждённое/неподтверждённое. Если в истории есть разрывы, результат намеренно остаётся «ожидает проверки».

## Запуск

Откройте `index.html` через веб-сервер или GitHub Pages. Для локального теста:

```bash
python -m http.server 8765 --directory god-preditor-spider
```

Затем http://127.0.0.1:8765/ . В отсутствие разрешённого доступа к Supabase страница честно показывает ошибку источника и не подставляет вымышленные коэффициенты.

## Права доступа и проверка Realtime

При отсутствии данных проверьте, что опубликованный клиентский ключ действителен, обе таблицы существуют, а политика RLS разрешает `SELECT` клиентской роли. Для Realtime таблица должна входить в публикацию `supabase_realtime` и иметь соответствующие права. Редактирование прав базы необходимо выполнять в собственном проекте Supabase после проверки текущих политик.

## Структура

- `index.html` — структура интерфейса.
- `styles.css` — оригинальное оформление GOD PREDITOR SPIDER LIVE.
- `app.js` — Supabase REST/Realtime, таблица, временная статистика, графики и анимация.
- `favicon.svg` — эмблема.

Проект не копирует серверную логику Premium и не обходит подписки. Из предоставленного JS использованы подтверждённые идеи показа подтверждённых раундов, истории и активных временных окон; самостоятельный интерфейс и расчёты обозначены как собственная статистическая реализация.
