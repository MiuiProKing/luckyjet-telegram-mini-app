## Confirmed prediction logic

The file contains a complete client-side `calculatePrediction(oddsArray, betAmount, settings)` implementation.

### Input/history window

- Automatic collector appends completed coefficients to `autoCoefficients`.
- A prediction is triggered automatically when `autoCoefficients.length >= 5`.
- The buffer is then cleared after the prediction cycle.
- Manual prediction requires at least 3 coefficients.
- When `excludeExtremes` is enabled, the sorted lowest and highest values are removed before analysis.
- `trendAnalysis` separately retains up to 10 recent values.

### Core statistics

- EMA smoothing factor: `0.2`.
- Volatility: population standard deviation.
- Trend: comparison of the last two processed coefficients (`up`, `down`, `stable`).
- Pattern detector: last 3 values; strictly rising => `bullish`, strictly falling => `bearish`, otherwise `neutral`.
- Pattern strength: `min(1, abs(diff1 + diff2) / 0.3)`.

### Analysis modes

`advanced`:
- recency weights are `1 + i*0.1`;
- prediction is the weighted arithmetic mean.

`pro`:
- `rawPrediction = 0.60 * EMA + 0.30 * mean + 0.10 * last`;
- if trend is up: multiply by `1.05`;
- if trend is down: multiply by `0.97`.

Default mode:
- arithmetic mean.

### Confidence adjustment

- `confidenceFactor = max(0.1, 1 - volatility*2)`.
- Displayed confidence is `round(confidenceFactor * 100)`.
- Before the safety margin, the prediction is further adjusted by:
  `rawPrediction *= (1 + confidenceFactor*0.1)`.

### Safety margin / target selection

`applyMargin()` applies a deterministic reduction to the calculated target:

- raw target `< 2.00`: subtract 15% (`x0.85`)
- `2.00 <= raw target < 3.00`: subtract 25% (`x0.75`)
- raw target `>= 3.00`: subtract 35% (`x0.65`)

The resulting value is the displayed/final target.

### Regression and global score

The last five processed values are used for a linear regression slope and local volatility.

Normalized components:
- `normalizedSlope = min(1, abs(slope)/0.25)`
- `normalizedVolatility = min(1, volatilityForRegression/settings.volatilityThreshold)`
- pattern: bullish `1`, bearish `0`, neutral `0.5`

Global score in this source:

`0.3*slope + 0.2*volatility + 0.1*pattern + 0.4*confidence + 0.1*patternStrength`

Note: these coefficients sum to 1.1, not 1.0. This appears intentional or is a coding oversight in the public source; no normalization step follows.

### Timing / verification rule

- Automatically generated predictions are queued into `pendingVerification`.
- User-facing text states that the final target should appear in one of the next **3 rounds**.
- The implementation therefore separates prediction generation from subsequent round validation.

### Data source classification

- Coefficients are API-returned from a public Lucky Jet state gateway referenced by the source.
- Prediction calculation itself is deterministic/heuristic given the same coefficient array and settings.
- No `Math.random()` appears in the inspected `calculatePrediction()` path.
- The final target is therefore not random in this implementation.
