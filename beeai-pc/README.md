# Классическая версия + BeeAI · 8 октября 2026

Старые Git-ветки, модели и игровые подключения сохранены. Новая страница использует тот же источник: прямой сборщик игры → SQLite на ПК → защищённый HTTPS-шлюз → браузер. BeeAI работает отдельным процессом на 127.0.0.1:8794 и не создаёт подключения к игре.

Из Beegram_3.3.4.ipa изучен незашифрованный Beegram.dylib. Найдены облачный клиент Gemini, system_instruction, личный ключ, роль, база знаний, история чата, переключение моделей. Веса Lucky Jet и исходный код нейросети не найдены. Облачная модель не извлечена и не обучена локально. Реализован совместимый подход, а не точная декомпиляция всего приложения. Instagram-автоответчик, Google OAuth, голос и жесты не переносились.

build.py извлекает исходные расчётные функции из классической страницы без изменения арифметики. evaluate_classic.cjs запускает их в отдельной VM без сети, со временем Europe/Kyiv. Gemini получает этот код, реальные результаты функций и завершённые раунды текущего подключения. Роль и дополнительные знания доступны в панели ИИ.

Ключ хранится только в ../luckyjet-sqlite-migration/.local/beeai.json. Он не входит в HTML, JavaScript, URL, отчёты или список публикации. Запросы Google используют x-goog-api-key. Не копируйте приватные папки в Git.

Запуск: Python beeai_server.py. Основной сборщик и шлюз должны уже работать. install.py добавляет ограниченный /api/beeai в существующий шлюз и запуск отдельного процесса в существующий supervisor; исходные файлы сохраняются в backup/. Старые страницы не требуют изменений. START-BeeAI.ps1 запускает только отсутствующие службы; нельзя запускать второй сборщик.

Проверка: Python tests.py; node --check evaluate_classic.cjs; node --check bog-hishchnik-alert/beeai.js. Публикация только через publish.py в новую ветку classic-beeai-pc-20261008. Файл адреса ПК используется с существующей classic-pc-live-20261006 и продолжает обновляться прежним механизмом.

ИИ работает максимум раз в 60 секунд, а не на каждое обновление интерфейса. Это внешний API, расходующий квоту ключа. Пауза доступна на странице; коэффициенты продолжают поступать независимо от ИИ. У 401/403/429 задержка повторения 10 минут. Ожидание, отказ от цели, ошибка, опоздание и пауза отображаются явно.

Дополнительный коэффициент — экспериментальный порог, а не точное значение будущего раунда. Сохраняются заранее зарегистрированные оценки с горизонтом 1–3 новых завершений, без перекрытия активных окон. Если ответ пришёл после нового результата, он помечается late и не засчитывается. При разрыве или устаревании — unknown. Исторические частоты не выдаются за вероятности. Порядок игры и начало следующего раунда независимо не подтверждены. Улучшение точности этим выпуском не доказано.

ПК должен быть включён, не спать и иметь интернет. Настройки питания не менялись. Telegram и ставки не используются. Старая остановленная автоматизация не возобновляется.
