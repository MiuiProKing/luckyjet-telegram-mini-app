GOD PREDITOR COMPLETE — бот Telegram

1. Установите Python3.10 или новее.
2. Установите зависимости: python -m pip install -r requirements.txt
3. Проверка без сообщений: python GOD_PREDITOR_COMPLETE.py --check
4. Запуск: python GOD_PREDITOR_COMPLETE.py

В личном файле уже сохранены ваши Supabase, новый токен бота и одна группа, выбранная в последнем сообщении.
Не публикуйте личный Python-файл на GitHub. Остановите прежнюю копию этого же бота перед запуском.
Бот работает без меню и кнопок включения, пока процесс запущен на хостинге.
Нужны постоянный Python-процесс, исходящий HTTPS, доступ на запись к папке скрипта.
Обычный статический хостинг HTML не исполняет Python-бота.

Автоматически загружается история Supabase за последние90дней, если она доступна; первая загрузка идёт в фоне.
История, созданные окна, результаты и доставки хранятся в god_complete.sqlite3.
После остановки сохраняйте этот файл и его -wal/-shm файлы или делайте штатную SQLite backup.
При отсутствии полной истории исход остаётся неопределённым, затем может уточниться после дозагрузки.
Прогнозы отправляются с исходной фотографией GoogleDrive; её точная копия встроена для резерва.
Поддерживаются BASIC, отдельные VIP-цели и временной клиентский модуль, диагностические варианты из Jt1.py.
Указанные проценты — оценки моделей, не измеренная вероятность выигрыша. Баллы правил показаны /100.
Точные серверные формулы чужого VIP/AI отсутствуют в публичном клиентском коде; их подлинность не заявляется.

В прогнозе отображается время Киева и целевой множитель; сумма ставки не выбирается.
После закрытия окна бот отправляет итог по фактическим завершённым раундам.
Бот не нажимает ставки и не обращается к игровому аккаунту.
