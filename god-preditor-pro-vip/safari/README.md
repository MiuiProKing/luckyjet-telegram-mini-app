# GOD PREDITOR · Userscripts Safari

Установка на iPhone: https://miuiproking.github.io/luckyjet-telegram-mini-app/god-preditor-pro-vip/safari/

Файл: [god-preditor.user.js](god-preditor.user.js). Официальное расширение [Userscripts](https://apps.apple.com/app/id1463298887), [инструкция автора](https://github.com/quoid/userscripts#usage).

## Как работает

Игра открывается самостоятельной страницей в Safari. Пользовательский скрипт в content-контексте расширения создаёт собственный Shadow DOM поверх неё. Это не iframe, прокси игры или обработчик ставок. Заголовок двигает панель, угол меняет размер, кнопка − сворачивает её в подвижную кнопку GP. × скрывает до перезагрузки. Положение, прозрачность и выбранная цель сохраняются через GM-хранилище расширения.

Метаданные разрешают запуск только на `https://one-vv3016.com/*` и нашей конкретной странице `preview.html`. `@noframes` и проверка `window.top` исключают запуск в игровых дочерних фреймах. Если зеркало изменит домен, оно не будет автоматически добавлено. Полный экран игрового iframe может скрывать внешнюю панель; в таком случае нужно выйти из него.

Скрипт использует те же исходники `window-model.mjs`, `modules/public-forecast.mjs`, `supabase-feed.mjs`, `supabase-config.mjs`, `data.mjs` и `scene.mjs`, что и основная страница. Отдельной копии или упрощённой формулы нет. Сцена имеет опциональный компактный режим; обычный режим основной страницы сохранён.

GM.xmlHttpRequest выполняет только GET к прежней таблице `luckyjet_rounds` нашего Supabase. Требуются прежние подтверждённые timestamps. Пароли, поля входа, баланс, cookies и содержимое игры не считываются. Кнопки игры не ищутся и не нажимаются. Единственный программный доступ к DOM сайта — добавление/восстановление собственной панели. Графические файлы загружаются с нашего GitHub Pages, удалённый JavaScript не загружается и не исполняется.

Это собственная сессия расчёта: фиксированные окна основной страницы и панели, запущенных в разное время, могут отличаться. Сохраняются последние 2000 раундов и 100 окон. Внутренняя история показывает последние 100 полученных раундов; полный архив остаётся функцией основной страницы. Вкладка в фоне останавливает опрос и анимацию, при возвращении подключается заново. Длительность/цель не меняются задним числом. Успех означает достижение цели любым раундом в окне, а не гарантированный следующий коэффициент.

## Сборка

Из корня репозитория:

```sh
npm ci --ignore-scripts --prefix god-preditor-pro-vip/safari
npm run build --prefix god-preditor-pro-vip/safari
npm run check --prefix god-preditor-pro-vip/safari
node --test god-preditor-pro-vip/tests/*.test.mjs
```

Esbuild закреплён версией и lockfile; файл — самостоятельный IIFE без import/eval/@require. Конечная строка адреса установки заканчивается `.user.js`, как требует Userscripts iOS. Исходники транспортного адаптера и интерфейса — `src/`, генератор метаданных — `build.mjs`. CI проверяет совпадение готового файла с исходниками.

## Проверка и ограничения

Проверены Promise/callback API по документации стабильной ветки Userscripts `release/4.x.x`, отмена запросов, ошибки, запрет записи и чужих API, фильтры подтверждённого времени и ограничение доменов. В мобильном Chromium с тестовым GM-адаптером проверены touch-перетаскивание и изменение размера, сворачивание, смена цели, история, прозрачность, восстановление положения/окон и отсутствие чтения поля пароля на изолированном стенде. В отдельной проверке с тестовым GM-адаптером панель успешно показалась поверх реальной страницы one-vv3016.com и загрузила 1000 подтверждённых раундов из Supabase; кнопки игры не нажимались. Проверено повторное внедрение при навигации, как при работе расширения. Установка расширения и его фактические разрешения на физическом iPhone требуют проверки пользователем; такая проверка здесь не имитируется.

Приложение Userscripts открывается один раз для настройки каталога. На странице `.user.js` в Safari нужно открыть меню Userscripts и выбрать Install. Простой просмотр файла или открытие через Telegram не устанавливает расширение. Если установка через меню недоступна, файл можно сохранить в каталог, выбранный в приложении Userscripts, затем открыть popup расширения и перезагрузить страницу.
