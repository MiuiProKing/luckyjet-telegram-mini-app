# Safari 1.5

Актуальная установка: [index.html](index.html), файл [god-preditor-1.5.user.js](god-preditor-1.5.user.js). Стабильный god-preditor.user.js совпадает с 1.5. Старый 1.1 сохранён для отката.

Используется исправленная экспериментальная TS-модель v2, сохранённая отдельно от исходника. Обе выбранные кнопки запускаются по времени основного прогноза. Режим по умолчанию выключен, тест не нажимает кнопки. Суммы и автозабирание скрипт не меняет.

Разрешены ровно one-vv3016.com, 1play.gamedev-tech.cc и наша отдельная preview.html. @noframes удалён: на игровом домене панель работает внутри его собственного документа, не обходит политику браузера. Мост между родителем и игрой передаёт только состояние видимости; не передаёт команды ставок, пароли или коэффициенты. Панель родителя закрывается после подтверждения запуска в игровом фрейме. Авто требует свежего состояния родителя, прекращается при его потере и при уходе в фон. Разрешение расширения на игровой домен пользователь включает в Safari.

Кнопки панели реагируют на доверенный pointer-up; отложенный click подавляется, чтобы одно касание не включало и сразу не выключало режим. Конфигурация выполняется прицелом без нажатия настоящих игровых кнопок.

Сборка: npm ci --ignore-scripts && npm run build. Проверка: npm run check. Сборка также компилирует modules/supplied/prediction.ts; оригинал вложения сохранён побайтно. Тесты запускаются из корня: node --test god-preditor-pro-vip/tests/*.test.mjs.

Физический iPhone и реальная ставка не проверялись автоматизированно. Используются локальные макеты с двумя разными HTTPS-origin, сенсорными событиями и фиктивными кнопками без денежных операций.

Верхняя строка управления: + увеличивает окно на 30×45 px, − уменьшает; ▁ сворачивает в GP, × закрывает. Кнопки не меньше 44×44 px; размер ограничен экраном и сохраняется. Заголовок, включая открытые настройки и историю, остаётся доступен.

## Исправления 1.4

Safari использует отдельную модель hardened-dynamic-windows-v4 из standalone prediction-v2.ts; основной сайт продолжает использовать прежнюю модель. Файлы 1.1/1.2/1.3 сохранены для отката. Улучшение точности не установлено: в отложенной проверке 454 полных основных окон исходник дал 68,28%, v2 — 68,72%, их собственная базовая оценка для соответствующих целей/длительностей — около 68,71%. Проверялось достижение цели любым раундом окна, а не выигрыш отдельной ставки. Дополнительные 100×+ окна не проходили эту проверку результативности.

Исправлены строгие входы/конфликтующие ID, анализ последнего непрерывного сегмента, статическая ошибка ETA, отдельная фиксация дополнительных окон и неправильная трактовка ожидания в Poisson. Балл теперь явно heuristicScore и не вероятность. Нужны20 свежих последовательных наблюдений; разрыв >180с прерывает анализ старого сегмента.

Новый ключ GM god-preditor-safari-v4 читает старый god-preditor-safari-v1 один раз как резервный при первом запуске и не перезаписывает его. История и настройки копируются; старые проверки остаются в отдельном legacyJournal и не влияют на новые результаты. Авто не восстанавливается, кнопки выбираются заново. Модель передаётся контроллеру явно, чтобы он обрабатывал только окна v4.

Проверка обновления 1.4: 91 Node-тест, контроль соответствия сборки и GET источника HTTP200. Браузерный макет qa-dynamic-frame.py обновлён под схему v4, в этой проверке не запускался. Физический iPhone и реальная ставка не проверялись.

## Автозабирание 1.5

Новый DOM-only режим работает только с явно выбранным пользователем текстовым живым коэффициентом и теми же двумя кнопками полей. Он выключен по умолчанию, тест не нажимает игру. Привязка не сохраняется после перезагрузки. Canvas/OCR/сокеты/скрытые API не используются.

Только callback после нашего отправленного Bet-клика создаёт зафиксированную цель; ни архив, ни текущая надпись прогноза, ни ручная ставка не подхватываются задним числом. До Bet-клика в режиме активного автозабирания повторно проверяются источник, часы и отсутствие незавершённого наблюдения. Сопоставление с новым полётом требует наблюдённого сброса или малого коэффициента и активной Cashout-кнопки, затем двух растущих свежих изменений. Значение должно достигнуть или превысить цель. На поле/сигнал — одна попытка, без повторения после неопределённого результата. Кнопка после запроса проверяется, но изменение её подписи не считается подтверждённой выплатой.

Закрытие поля после ожидания, сброс или конец полёта прекращают текущее наблюдение и оставляют режим ожидать новую автоставку по новому прогнозу. Повторной ставки в старом окне нет. Сумма и штатный автовывод не меняются. Ручное доверенное нажатие выбранной кнопки, скрытие/перезагрузка, потеря источника и ошибки часов выключают отслеживание; критическая ошибка выключает также будущие автоставки.

Ограничения: реальная игра/серверные roundId и stakeId не проверены; совпадение определяется эвристикой интерфейса. Публичный корень игрового домена вернул403, доступный код не подтвердил DOM-счётчик. Поэтому работоспособность на текущем LuckyJet не заявляется до проверки выбранного пользователем текста. Всегда открытый Safari не устраняет задержку кадров, DOM и сервера. Это не гарантия вывода точно по порогу или прибыли. Все новые тесты — Node-макеты, реальные деньги не использовались.

Проверка1.5: 160 Node-тестов, воспроизводимая сборка и синтаксис установочного файла. Общий набор включает DOM-макеты, контроллер, связь Bet→Cashout и ожидание нового прогноза после незавершённой цели. На физическом iPhone, настоящем игровом DOM и реальных деньгах версия не проверялась. Математика модели v4 и Poisson-диагностика в1.5 не усиливались непроверенным бонусом за ожидание.
