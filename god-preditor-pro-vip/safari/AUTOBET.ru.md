# Автонажатия · 1.5

Обе выбранные кнопки работают по одному основному динамическому прогнозу из присланного TypeScript. Дополнительное окно не запускает их. Суммы и автозабирание выставляет пользователь сам. После обновления выбери обе кнопки заново и сначала используй «Тест без ставок».

Режим по умолчанию выключен и не восстанавливается после перезагрузки. Одно нажатие на поле/окно, отметка сохраняется до действия; повторений при неопределённом ответе нет. Опоздание, скрытие, потеря источника, смена кнопки, занятое поле или отсутствие подтверждения выключают режим либо пропускают окно. Максимальное ожидание доступности — 15 секунд; уже открытое при включении окно пропускается. Требуется блокировка вкладок Web Locks. Обычный программный click может быть отклонён игрой; принятие ставки проверяй в игре. Успех окна по истории не подтверждает выигрыш конкретной ставки.

Для фрейма 1play.gamedev-tech.cc нужно разрешение Userscripts на этот домен. Скрипт работает непосредственно внутри него. Состояние видимости родителя проверяется мостом без команд действий. При отсутствии heartbeat автоматические нажатия запрещены.


Автозабирание1.5 включается отдельно после привязки живого DOM-коэффициента. Порог закрепляется при отправке новой ставки нашим скриптом и больше не меняется. Режим ждёт активную кнопку «Забрать» и признаки нового полёта, затем рост живого числа; при достижении/превышении цели отправляет один запрос. Если полёт закончился раньше — ждёт новый прогноз; не повышает сумму и не повторяет ставку по старому сигналу.

Проверка DOM-источника на реальной игре обязательна: Canvas не поддерживается, серверные ID раунда/ставки не подтверждены, сетевые задержки остаются. Тестовый режим не делает нажатий. Сохранять включение и привязки после перезагрузки запрещено логикой. Оба поля/счётчик должны быть в одном документе. Более низкий встроенный автовывод игры имеет приоритет. Нажатие и смена текста кнопки не являются доказательством принятия ставки или выплаты.
