GOD PREDITOR COMPLETE V3 — готовый Telegram-бот

Python 3.10+. Зависимости: python -m pip install -r requirements.txt
Проверка без Telegram-сообщений: python GOD_PREDITOR_COMPLETE_V3.py --check
Запуск: python GOD_PREDITOR_COMPLETE_V3.py

В личный файл вписаны новый токен, одна выбранная группа и наше подключение Supabase. Не публикуйте личный Python-файл на GitHub. Публичные исходники выдаются отдельно с примером конфигурации. Перед запуском V3 остановите прежний экземпляр этого же Telegram-бота, чтобы две программы не отправляли сообщения параллельно.
Бот автоматически работает без меню и кнопок включения, пока Python-процесс запущен на хостинге. Статический HTML-хостинг не запускает Python.

Сайт и бот читают один канонический серверный журнал Supabase. ID, цели, время начала, границы и исходы одинаковые. Бот не создаёт другие окна самостоятельно и не заменяет сервер локальной моделью при обрыве соединения. Часы берутся из ответа сервера.
Все каналы моделей включены на сервере и доступны сайту: основной Premium, BASIC, отдельные крупные цели, шесть временных длительностей и три прогноза по числу раундов. Локальные исходные функции и пять дополнительных вариантов сохранены полностью; их можно изучить в исходниках или получить только локальный отчёт: --offline-analysis history.json. Такой режим не отправляет сообщения.

В группу по умолчанию отправляются главный Premium и отдельные крупные цели10/40/200/500. Это настройка доставки, а не выключение остальных расчётов. Для отправки всех каналов задайте переменную PUBLISH_CHANNELS=all перед запуском. Можно перечислить нужные имена через запятую: premium_live,basic,vip_10,vip_20,vip_40,vip_50,vip_100,vip_200,vip_500,big_cycle100,big_hot_cluster,duration_3,duration_6,duration_7,duration_10,duration_30,duration_61,rounds_5,rounds_10,rounds_100.
Не смешиваются оценки разных эвристик в выдуманный общий процент. Основной вывод — выбранная исходным Premium-правилом цель; крупные сигналы помечены отдельно.

После первого фото Telegram file_id сохраняется и используется для ускорения. Исходное изображение Google Drive встроено как точная резервная копия. Фото и полный русский текст отправляются раздельно, поэтому длинный прогноз не обрезается лимитом подписи.
Публичные контактные кнопки Instagram/Telegram разработчика сохранены. Кнопок управления прогнозами нет.

Для временного окна итог приходит после закрытия; при недостаточной полноте истории исход UNKNOWN, а не проигрыш. Для прогноза на N раундов проверяется число реально полученных завершённых раундов; ориентировочное время не является жёсткой границей. Каноническое подтверждение цели может закрыть такое окно раньше N.
Результат предыдущего окна имеет приоритет в очереди перед следующим прогнозом. Учитываются групповые лимиты Telegram, ответ429, перезапуск и неоднозначная отправка. Запоздалые прогнозы не переносятся на новое время: они пропускаются. При включении всех каналов лимит Telegram может не позволить доставить каждое короткое окно; все окна остаются в общем серверном журнале.

На Python-хостинге папка скрипта должна быть доступна для записи и сохраняться между перезапусками. god_complete_v3.sqlite3 хранит только состояние доставки, курсор общих событий и локальную копию параметров. Не удаляйте его при обычном обновлении. Данные моделей и история событий находятся в Supabase.
Неопределённые исходы могут позднее уточняться после появления полной истории. После перезапуска не отправляется весь старый архив сообщений. Прогнозы, которые уже почти закончились, не объявляются заново.

Проценты — оценки при допущении модели, а не измеренная точность отдельного раунда. Баллы правил выводятся /100. Закрытые серверные веса чужого AI не получены; наличие надписи AI не доказывает нейросеть. Бот не выбирает сумму ставки и не нажимает кнопки игры.
