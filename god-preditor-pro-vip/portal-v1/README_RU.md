# GOD PREDITOR — портал версий

Отдельная главная страница со входом и ручным одобрением аккаунтов GOD PREDITOR.

## Для владельца

Данные администратора находятся в отдельном личном файле `GOD_PREDITOR_ADMIN_PRIVATE.txt`. Его нельзя загружать на публичный хостинг или GitHub. Войди через «Вход администратора», открой «Заявки» и одобри нужного пользователя. Затем передай ему общий код доступа отдельно. Заявки видны в кабинете; почтовые уведомления сейчас не подключены.

Пользователь создаёт свой логин, контактный email и новый пароль GOD PREDITOR. После одобрения входит со своим паролем и общим кодом. Пароли не отправляются владельцу и не доступны в кабинете: сохраняются только PBKDF2-SHA256 хеши. Кнопка отзыва доступа прекращает активные сеансы пользователя.

## Публикация

Содержимое `site/` — готовая статическая страница. `index.html` должен лежать в корне папки на хостинге; рядом должны быть `app.mjs`, `styles.css`, `config.mjs`, `icon.svg` и `assets/`. Сборка Node.js не нужна. Подключение к выделенному API Supabase указано в публичном `config.mjs`; закрытые ключи там отсутствуют.

Каталог возвращается API только после проверки одобрения, пароля и кода. Все пять версий открываются по исходным пользовательским ссылкам. Пароли и токены в эти ссылки не передаются. Уже опубликованные внешние страницы по прямым адресам остаются публичными: этот портал управляет только своим входом и каталогом.

## Исходный проект

`server/` содержит выделенный API, код проверки паролей и схему новых таблиц портала. Старые версии GOD PREDITOR, таблицы истории коэффициентов, модели и боты не меняются. Секреты запуска и аккаунт администратора не включены в открытый архив сайта.

Нельзя просто открыть HTML как файл на телефоне: используй HTTPS-хостинг. Для локальной проверки запусти HTTP-сервер из `site/`.
