# GOD PREDITOR · PRO VIP

Отдельная версия страницы с неоновым мозгом, электрическими щупальцами и пауком, переносящим реальные коэффициенты. Пять свежих коэффициентов, время по Киеву, полный архив полученной истории, цели 1,50× / 2× и проверка следующего раунда. Буквы, VIP и анимированные значки результата извлечены из присланных пользователем видео.

Открыть: https://miuiproking.github.io/luckyjet-telegram-mini-app/god-preditor-pro-vip/

Исходники сохранены в ветке `release/pro-vip`. Для публикации GitHub Pages та же папка добавлена в `main`; существующие страницы не изменяются.

## Локальный запуск

Из корня репозитория:

```sh
python -m http.server 8080
```

Открой http://localhost:8080/god-preditor-pro-vip/. Сборка и установка зависимостей не нужны.

## Данные и проверка

`supabase-config.mjs` содержит прежний URL и публичный publishable key Supabase. База `luckyjet_rounds` только читается. Локальная история хранится в IndexedDB этого браузера; доступна догрузка полной истории и экспорт. История другого домена не переносится автоматически.

Исход фиксируется для одного следующего раунда после снимка оценки. Анимированный результат появляется один раз на 4,5 секунды; новые проверки продолжаются автоматически. Пропуски и устаревшие данные не выдаются за попадания. Расчёт описывает прошлые данные и не гарантирует следующий исход; время — ориентир темпа потока.

## Анимации

В assets включены только изолированные буквы и значки, без записей экрана или интерфейса Telegram. Яркость поднята из-за затемнения видео; перекрытый участок рамки VIP восстановлен симметрией. Для reduced-motion есть статичные кадры. Электрические щупальца адаптированы по референсу https://tuberboy.github.io/weird-monster/monsterelectrico.html; мозг и паук — Canvas.
