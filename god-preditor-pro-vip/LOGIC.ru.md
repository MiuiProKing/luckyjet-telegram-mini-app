# Расчёт из присланного файла · v3

Активная модель `supplied-dynamic-windows-v3`. Файл `modules/supplied/prediction.ts` — точная копия присланного TypeScript. `1993.txt` сохранён рядом: он повторяет алгоритм, но содержит повреждённые операторы и строки. Арифметика берётся из исправного TypeScript и компилируется esbuild в `modules/supplied-prediction.mjs`. Отсутствовавший модуль analysis-data реализован фильтрами исходного публичного архива: время провайдера, сортировка, исключение будущего и повторов, свежесть 180 секунд. Минимум — 20 раундов.

Ограничение 1,50× / 2× удалено. Основной коэффициент, время, длительность, confidence, reliability, pattern и basis возвращаются исходной функцией `generatePrediction`.

| Правило исходника | Пороги и результат |
| --- | --- |
| Устойчивый цикл крупных событий | События ≥10×, минимум 8; медиана и MAD интервала; цель 2–20× |
| Низкая серия | Последние 15 раундов <2×; геометрическое среднее и медиана; цель 2,5–15× |
| Плотный крупный кластер | От 3 событий ≥20× в последних 30; цель 2–12× |
| Средний кластер | От 3 событий 5≤x<10 в последних 60; цель 2–7× с учётом нестабильности |
| Смешанный расчёт | EMA20/EMA50, среднее, геометрическое среднее, σ/MAD, UTC-профили часов и минут; цель 1,8–12× с исходными ограничителями |
| Дополнительное окно | Цикл событий ≥100×, кластер ≥50×/≥20× или Poisson-оценка задержки; исходная цель 100× либо 120× |

Дополнительное окно не подменяет основной прогноз, даже если его балл выше. Переключатель «Основной / Доп. окно» выбирает отображение. Если дополнительного расчёта нет, окно не выдумывается. Исходные `raw` и `opportunity` доступны в JSON-журнале. Балл /100 — эвристическая оценка, не вероятность выигрыша. История независимых случайных исходов не даёт гарантии следующего коэффициента.

Основной прогноз заморожен до окончания своего окна. Успех проверки — хотя бы один фактически полученный раунд ≥ рассчитанной цели внутри окна, а не предсказанный следующий раунд. Промах требует непрерывного покрытия и успешного свежего опроса после конца окна; иначе результат неизвестен. Ранний успех не создаёт перекрывающий новый прогноз. Время показывается по Киеву, расчёт часовых профилей остаётся в UTC.

Данные идут из прежней таблицы Supabase `luckyjet_rounds`: только completed=true, estimated=false, с round_timestamp. История и оформление сохранены; старый журнал основной страницы вынесен в legacyJournal при миграции. Автоматические нажатия по умолчанию выключены. Обе вручную выбранные кнопки относятся ко времени основного прогноза, не к дополнительному ≥100× окну. Суммы и автозабирание пользователь проверяет и устанавливает сам; скрипт их не меняет.

Старая модель сохранена в `legacy-window-model.mjs`, описание — `LOGIC-small-v2.ru.md`, установленный файл Safari 1.1 также сохранён.
