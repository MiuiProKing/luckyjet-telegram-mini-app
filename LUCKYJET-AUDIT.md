# Lucky Jet PRO: обновление по клиентскому аудиту

Сохранены исходные функции De/Ce из публичного PredictionPanel-BX01Z_sa.js (SHA-256 `46f71171c554726c040a124679f7efb87e9fdded79ccb1f730a4b9caff2686e8`). Используется существующий источник истории приложения; серверный сборщик не изменён.

## Изменения

- Валидация коэффициентов, времени и ID. Невалидные записи исключаются, повторы ID удаляются, разные раунды с одинаковым коэффициентом сохраняются. При одинаковом времени используется устойчивый порядок ID.
- Запросы истории выполняются последовательно и объединяются по ID. Старый снимок не стирает свежие данные. Конфликтующие ID не подтверждают попадания.
- Модель содержит до 2000 раундов. API фактически ограничивает ответ 1000 записями, поэтому добавлена подгрузка следующей страницы с повторной проверкой начала списка.
- Точные формулы используются только при точном времени последних 20 раундов и свежей истории. В остальных случаях доступны правила последовательности/кластеров с пометкой времени ≈; временные циклы и часовые группы отключены.
- Цель и окно сохраняются до результата или окончания; учитываются все раунды окна. Для подтверждённого промаха нужны точные данные, непрерывные обновления и финальная свежая проверка. После перезагрузки и при пропусках исход остаётся непроверенным.
- Балл модели показывается как N / 100. Статистика сигналов отделена от частоты коэффициентов ≥2×; приблизительные наблюдения и непроверенные окна показаны отдельно.
- Архив фильтруется по местному календарному дню, включая новые раунды. Статистика явно относится к загруженной части; лимит отображения — 10 000 записей.
- GitHub Pages обновляется при изменении PRO-страницы и новых модулей; CI проверяет UTC и Europe/Kyiv.

## Проверки

27 сценариев проверяют формулы, одинаковое время, невалидные значения, дубликаты, устаревшую историю, неточное время, фиксацию цели, границы окна, четвёртый раунд, отсутствие связи, остановившийся источник при успешных запросах, восстановление, перекрывающиеся запросы, задержанный снимок, API-лимит 1000, архив, статистику и ручной диапазон.

```sh
TZ=UTC node tests/pro-luckyjet-audit.test.mjs
TZ=Europe/Kyiv node tests/pro-luckyjet-audit.test.mjs
node --check pro-luckyjet-engine.js
node --check pro-luckyjet-app.js
```

Браузерная проверка на искусственном источнике: выборка 2000, создание сигнала, сохранение цели после перезагрузки, пометка пропущенной проверки, отсутствие переполнения на 390×844 и ошибок страницы. Живой API проверен отдельно: HTTP 200, 1000 записей на ответ, все полученные временные метки помечены как приблизительные.

## Ограничения

Баллы правил не являются подтверждённой вероятностью выигрыша. Бонус +5 нескольких крупных правил не проверяет независимость, а Пуассон использует прошедший интервал. Серверная логика чужого сайта и будущие игровые исходы не получены. Формулы воспроизводят публичные эвристики по истории.

Существующие доступ, языковой интерфейс и интеграция Telegram Mini App сохранены. Telegram Web и другие игры не исследуются этим обновлением.
