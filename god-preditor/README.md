# GOD PREDITOR — Lucky Jet

Папка содержит две части:

- `index.html` — мобильная HTML-панель Lucky Jet для GitHub Pages.
- `bot.py` — Telegram-бот с автоанализом, большим коэффициентом и проверкой результата по раундам.

## HTML

Открой страницу, зайди в `⚙️ Подключение Lucky Jet` и один раз введи `customer-id` и `session-id`. Они сохраняются только в `localStorage` браузера и не записываются в GitHub.

Функции страницы:

- основной прогноз;
- уверенность;
- прогнозное окно;
- возможный большой коэффициент;
- последние коэффициенты;
- средний/максимальный коэффициент;
- частота ≥2X и ≥10X;
- ручной и автоматический анализ;
- проверка `✅ ЗАШЛО / ❌ НЕ ЗАШЛО`;
- номер раунда, в котором достигнута цель;
- локальная статистика результатов.

## Telegram bot

Перед запуском установи:

```bash
pip install pyTelegramBotAPI requests
```

Нужные переменные окружения:

```text
TELEGRAM_TOKEN
GROUP_CHAT_ID
LUCKYJET_CUSTOMER_ID
LUCKYJET_SESSION_ID
LUCKYJET_API_URL   # необязательно
POLL_SECONDS       # необязательно, по умолчанию 5
```

Запуск:

```bash
python bot.py
```

GitHub Pages запускает только HTML/JS. Python-боту нужен отдельный постоянно работающий сервер/хостинг.

Статистический анализ не гарантирует будущий коэффициент.
