# AP Collector

Экранный сборщик для iOS, предназначенный для пользовательского захвата видимых данных из AllPredictor или других приложений.

## Что делает

- На iOS 27+ открывает системный ScreenCaptureKit picker для полного экрана.
- После явного разрешения пользователя продолжает получать кадры, когда приложение находится в фоне.
- Vision OCR распознаёт видимые коэффициенты вида `1.23x`, URL и релевантные строки.
- Пишет `allpredictor_capture.json` и `allpredictor_capture.csv` в контейнер приложения.
- Экспортирует файлы через стандартное меню «Поделиться».

## Важно

Приложение не расшифровывает HTTPS, не получает скрытые API-ключи и не обходит подписки. Оно анализирует только изображение экрана, которое пользователь явно разрешил захватывать.

## Сборка

Проект генерируется XcodeGen из `project.yml`. Исходник специально не импортирует заголовки ScreenCaptureKit: iOS 27 API подхватывается динамически в runtime, поэтому проект можно собрать стабильным Xcode 26.x, а функция полного захвата активируется на устройстве с iOS 27+.
